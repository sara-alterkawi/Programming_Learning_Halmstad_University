## 🗝️ About This Repository

This repository collects the **project work from my university studies (2021–2025)**.

It focuses on:

- 🔌 Embedded and Computer Systems Engineering
- ☕ Object-Oriented and Concurrent Programming in Java
- 🌐 Distributed Systems and Networking
- 🤖 Full-Stack Development
- 📐 Numerical Computing

Each project folder contains its own source code and description.

## 🎯 Learning Objectives

The main objectives of these projects were to:

- 🔌 Program embedded hardware in C (sensors, actuators, interrupts, timers).
- ⏱️ Understand real-time and low-level system behavior.
- 🏗️ Apply Object-Oriented Programming principles and design patterns.
- 🌐 Build networked and API-based applications.
- 🔄 Work with concurrency and synchronization.
- 🤝 Collaborate in teams using Git and GitHub.

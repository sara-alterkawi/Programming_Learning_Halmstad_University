# Programming Learning – Halmstad University

A collection of projects from my B.Sc. in Computer Science and Engineering (Dataingenjör) at Halmstad University, Sweden.

The projects cover:
- **Embedded and computer systems:** programming microcontroller hardware in C
- **Software development in Java:** object-oriented design, networking, concurrency and REST APIs
- **Full-stack and web development:** including a robot control project with a web interface
- **Numerical computing:** MATLAB

Each folder contains one project, with its own description and source code.

## Languages
C, Java, Python, MATLAB, HTML/CSS/JavaScript
